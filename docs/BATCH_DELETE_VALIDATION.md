# 误填报销批次删除：2026-10-12

用户最新要求为直接删除误填批次，不需要恢复功能。报销记录详情提供一次明确确认：删除整批及全部分配、同时撤销相关核销、无法在软件中恢复、资金不变。取消或关闭不写入。已撤销批次也可删除，不重复释放额度。没有回收站或恢复命令。

实现将目标从 `state.batches` 移除；`batchEvents` 仅保存 requestId、操作时间、删除前完整批次及 `after:null`，与状态和请求表同一 SQLite 事务。没有 SQL 表结构迁移。批次新编号计入已删除审计中的历史最高编号，避免复用。旧账本读取不回填历史。删除只针对报销登记，不能用于真实费用退款。
