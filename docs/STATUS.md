## 已经能用的功能

| 范围 | 说明 |
| --- | --- |
| 费用 | 接待、办公两类。新增、查看、筛选（日期范围、关键词、报销状态）、纠错、删除误填。可附一张支付截图作为凭证（金额等全部手动填写） |
| 预支 | 新增、查看、修改、删除误填，可附一张到账截图 |
| 余额 | 全账本预支减费用，允许负数并显示“本人垫付”，不受筛选影响 |
| 报销 | 分批、合并、跨类别、部分报销；报销记录页可检索、看明细、撤销、删除误填批次。报销不改变余额 |
| 开票提醒 | 费用详情里勾选“是否已开票” |
| CSV | 导出当前筛选的全部费用（9 列） |
| 数据和备份 | 账本、截图、备份都在钱来文件夹里，复制整个文件夹即可搬家。每天自动备份（保留最近 30 份）、立即备份、预览后从备份恢复、从其他文件夹（旧版钱来或 U 盘上的备份）导入、确认后清空；恢复和清空之前自动备份当前账本。账本损坏时可以改名保存后用空账本打开，再从备份恢复 |
| 界面 | 雾紫白主题；总览、接待、办公、报销记录、预支、备份六个页面；列表每页 6 条 |

具体规则见 [BUSINESS_RULES](BUSINESS_RULES.md)。
