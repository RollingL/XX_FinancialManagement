## 已经能用的功能

| 范围 | 说明 |
| --- | --- |
| 费用 | 接待、办公两类。新增、查看、筛选（日期范围、关键词、报销状态）、纠错、删除误填。可附一张支付截图，本机 OCR 辅助填写金额、日期、商户，人工确认后保存 |
| 预支 | 新增、查看、修改、删除误填，可附一张到账截图 |
| 余额 | 全账本预支减费用，允许负数并显示“本人垫付”，不受筛选影响 |
| 报销 | 分批、合并、跨类别、部分报销；报销记录页可检索、看明细、撤销、删除误填批次。报销不改变余额 |
| 开票提醒 | 费用详情里勾选“是否已开票” |
| CSV | 导出当前筛选的全部费用（9 列） |
| 备份 | 完整备份、预览后恢复到新目录、确认后清空（受管模式） |
| 界面 | 雾紫白主题；总览、接待、办公、报销记录、预支、备份六个页面；列表每页 6 条 |

具体规则见 [BUSINESS_RULES](BUSINESS_RULES.md)。

## 已知问题

完整清单和建议见 [审查报告（2026-11-27）](REVIEW_2026-11-27.md)。最重要的四条：

1. Windows 版数据放在程序文件夹里，升级要手动复制，容易丢数据。
2. 没有自动备份。
3. 启动锁依赖 PowerShell 查询，异常退出后可能一直提示“账本正在使用或有残留锁”。
4. 最新代码没有在 Windows 10 真机上验收过。

## 下一步

等用户决定。建议顺序（详见审查报告最后一节）：

1. 搭安全网：PR 自动测试、补回核心测试、代码格式化（不改功能）。
2. 保护真实数据：自动备份、数据目录与程序分离、简化启动锁。
3. 出新 Windows 包并在 Windows 10 真机验收。
4. 再做新功能。
