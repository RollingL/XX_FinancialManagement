## 九项实现及规则

| 反馈 | 最终行为 |
| --- | --- |
| 发票历史锁住费用 | 当前纯关联、解除历史及旧票额标记均不锁住费用编辑。保留编号、原图及审计；有效报销时金额不得低于有效已报销合计。纠错不代替实际退款 |
| 发票不分配额度 | 新关系为费用编号集合；兼容旧 allocations 的费用关联。旧金额仅保留历史，不进入资金或报销；缺票按当前关联/旧标记判断，CSV改为11列（关联发票编号、发票状态替代票额覆盖列） |
| 费用删除 | 一次明确确认后移除误填支出、重新计算余额、解除当前票据关系，保留审计原图及稳定编号。有效报销分配存在时阻止删除，需用户先自行撤销相关批次，不自动冲销任何批次；已撤销/删除历史保留 |
| 预支编辑删除 | 编辑到账金额/日期/备注，附件保留；删除用0金额墓碑保留数组下标/稳定编号和审计。旧记录缺失日期不自动编造。纠正误填会影响余额，真实退还预支仍未实现 |
| 发票编辑删除 | 修改元数据及金额保留身份查重、编号、原图和费用关系；删除移除当前材料关联，历史原图与审计保留，不改费用、资金或报销金额 |
| 新报销选择发票 | 可不选；选票后逐笔勾选本次正数分配中的费用。发票、明确关系和报销批次同事务；修订过时/无费用/非本次费用拒绝，失败无半笔。批次保存材料关系快照展示，后续票据删除不改批次金额 |
| 恢复备份 | 原生目录选择、严格完整校验/内容预览、准确文字确认、恢复前自动完整备份、恢复到新managed根并原子切换入口。原根及备份保留；源变化/状态变化/伪造token拒绝；旧代际请求拒绝；请求+token+原代际幂等回执跨重开。持久化警告在刷新后仍显示 |
| 图片预览 | 点击图片完整模态预览，去除冗余放大原图入口；长图滚动、Escape、关闭、焦点返回及底层抽屉不误关 |
| 布局收拢 | 保留雾紫白主题，统一控件/内卡/面板圆角。七页与十一类抽屉在三种窗口尺寸检查，文档无横向溢出，长表单独立滚动，底部按钮可见 |

附件被删除审计引用时保留受管原图，以保持备份与历史证据完整；不删除外部原图。正式写入在事务中复核原值/修订，幂等请求和操作审计同时保存。没有引入新框架或依赖。
