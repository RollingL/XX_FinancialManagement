# 钱来 Windows 10 x64 离线试用候选

本包供 Intel／AMD 64 位 Windows 10 合成数据试用。它是完整解压运行的便携包，不是安装器；包含 Electron、SQLite、Python OCR 辅助程序、模型、字典和应用本地运行库。目标电脑不用安装 Node、Python，也不用下载模型。Windows Server 构建机上的探针结果不等于你的 Windows 10 已验收；首次断网运行结果仍需实际记录。

## 从 U 盘开始

1. 将 ZIP 和同名 SHA256 文件复制到电脑。在磁盘上选择全新、可写的文件夹，完整解压 ZIP。不要覆盖旧版本或已有账本，不要只复制其中一个 exe。
2. 保持电脑断网，双击解压目录里的 `START-TEST.cmd`。它为本包创建独立的 `trial-data` 试用账本和 `backups` 备份目录；首次打开应为空账本。不要直接打开 `app` 里的 exe，因为它没有这个隔离启动配置。
3. 只填写虚构数据。关闭应用后保留整个文件夹；再次通过同一个 `START-TEST.cmd` 启动，可继续原来的试用账本。

可选校验：在 ZIP 所在目录打开命令提示符，运行 `certutil -hashfile "完整ZIP文件名.zip" SHA256`，与同名 `.sha256` 中的 64 位值逐字比较。包内 `build-info.json` 记录源码版本，`file-hashes.json` 记录每个文件的大小和哈希。

如果出现安全软件、SmartScreen 或公司策略阻止，停止并记录提示。不要关闭保护或修改策略。启动失败也不要删除已有 `trial-data` 或其中的锁文件。

## 建议试用顺序

- 确认从空账本开始。新增一笔虚构预支 1000.00 元，余额应为 1000.00 元。
- 新增费用并选取随包 `samples/synthetic-payment.png`，验证首次离线识别。人工核对后保存费用 1280.50 元，余额应为 -280.50 元，本人垫付为 280.50 元。图片只能是 PNG/JPEG；PDF 尚未支持。
- 给这笔费用登记报销 500.00 元，待报销应为 780.50 元，余额仍为 -280.50 元。报销登记不会再次到账。
- 在发票页归档一张虚构 PNG/JPEG，手工确认虚构发票身份和票面金额 1280.50 元，再勾选关联这笔费用；不再分配发票额度。确认、补图和关联都不改变余额或报销进度。归档不自动生成费用；补图不增加票额。
- 检查费用详情和关联详情、列表搜索、每页六条、当前筛选结果 CSV 导出。CSV 包含全部筛选页，不按勾选项导出；没有路径或附件内容。
- 在备份页创建完整备份。备份在本包的 `backups` 中，账本和原图附件都应保留。正常关闭窗口，再启动，验证记录、原图、关联和金额仍在。备份页可选择完整备份目录，校验和预览后输入“恢复备份”。确认后自动完整备份当前账本，恢复到新受管目录并切换入口；原目录保留。请保留整个 trial-data，不要手工替换正在使用的 SQLite 文件。
- 费用当前发票关联及解除历史均不锁住编辑，已撤销报销历史亦允许编辑。有有效报销时，金额不能低于有效已报销合计；删除需先自行撤销相关批次，不自动冲销其他费用。纠错或误填删除不是退款。
- 分别测试预支和发票的修改／删除确认。预支纠正影响余额，发票不影响资金或报销；审计原图保留。新报销可不选发票，也可逐票勾选本次正数分配中的费用。点击任意附件图片打开完整预览，Escape 返回原面板。

遇到运行问题，可以在关闭应用后双击 `CHECK-RUNTIME.cmd`。它只运行随包合成 SQLite／OCR 探针，结果保存在 `trial-data/probe-result.txt` 和 `probe-error.txt`；不改业务账本。

此包包含2026-10-13已验收基线的九项修订。此前用户认可Windows同阶段验收；此新包的CI检查不等于新包已做Windows10真机首次断网／原生UI复测，公司策略、签名、安装升级／卸载仍未验证。Windows OCR 辅助进程目前没有与 Mac 相同的操作系统禁写约束，因此本轮只使用合成素材。不要将它作为唯一财务存档。源码、构建步骤和候选包均保持私有，不通过此包开启云 OCR、税务验真或银行服务。
