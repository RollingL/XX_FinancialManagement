# 钱来 Windows 离线版使用与升级说明

目标环境为 Windows 10 x64。便携包随附 Electron 和 SQLite，目标电脑无需另外安装任何软件。请保留完整目录。包内 build-info.json 记录来源提交，随 ZIP 提供的同名校验文件记录 SHA-256。

## 首次使用

1. 将完整 ZIP 复制到电脑，用 Windows“全部提取”解压到当前用户可写的本地目录，不在 ZIP 内运行，不放入 Program Files 或网络共享。
2. 双击根目录 **Qianlai.exe**。日常使用没有 CMD 窗口；内部 app 目录由启动器管理。
3. 首次为空账本。费用的金额、日期、商户手动填写，可附一张支付截图作为凭证。费用保存后影响余额；公司到账统一登记预支；报销登记只更新进度，不增加到账。允许负余额，“本人垫付”按负余额计算。
4. 使用窗口的关闭按钮退出。正在保存时应用先等待收尾。应用已运行时再次双击，已有窗口会回到前台。

程序会在根目录生成 `trial-data`（沿用旧版本名称，内含全部账本、附件、活动入口及恢复根）、`backups`（完整备份）和需要时的 `diagnostics`（日志）。这些目录不属于可丢弃缓存。

## 升级已有账本

请保留旧软件完整目录，升级前先在旧版“备份”页导出完整备份。若旧版无法打开，保留完整原目录，先处理启动占用问题，不删除锁或数据库。

1. 正常关闭旧版，确认其窗口已退出；不要同时打开旧、新版本写同一份账本，不复制正在写入的 SQLite 文件。
2. 新版完整解压到**另一个空目录**，先不要启动。
3. 将旧版整个 `trial-data` 和 `backups` 文件夹**复制**到新版根目录。必须包含 `user-data` 中所有同级 `restored-*` 目录、活动指针及附件，不能只复制 `trial.sqlite`。旧目录保留不动；若新目录已有同名数据，停止，不覆盖或合并。
4. 双击新版 `Qianlai.exe`，核对预支、费用、报销、余额、附件及开票标记；核对后再导出一份完整备份。新版接受旧版包标识，不因构建编号变化重置账本。

开票提醒是费用详情的独立勾选项。旧费用没有此字段时显示未勾选，不从历史发票推断。旧发票及关联历史仍保留在完整备份，管理页面已移除。新提醒审计可能不被旧版识别；不要把升级后的数据覆盖回旧软件目录。

## 备份与恢复

“备份”页的“导出完整备份”保存账目、开票标记、历史和原图附件；CSV只是当前筛选明细，不能用于恢复。

恢复时选择完整备份文件夹，等待校验与预览，准确输入“恢复备份”。软件先完整备份当前账本，再将选中备份恢复到新的受管目录，最后切换入口。原账本保留，校验或发布失败不会覆盖原账本。请保留整个 `trial-data`，不要手动搬动其中单个恢复根或活动指针。

“清空所有数据”需要准确确认文字，删除当前账本业务与受管附件，软件内不可撤销；外部原图、另存备份及其他目录保留。不要用清空、改原额或删除记录代替真实退款／退还预支，相关业务尚未支持。

## 启动异常时获取最小日志

先保留完整目录，记录错误框原文及出现步骤。不要删除 `.writer-lock`、修改数据库或关闭安全软件。

- 双击根目录 `START-TEST.cmd` 可进入一次诊断启动。窗口会保留退出码，日志写入 `diagnostics/start-*`，不另建或切换业务数据目录。
- `CHECK-RUNTIME.cmd` 仅用临时数据检查 SQLite 能否运行，结果写入 `diagnostics/probe-*`，不打开业务账本。
- 一般启动阶段日志位于 `trial-data/user-data/logs/startup.log`，只记录阶段、PID及退出状态，不记录账目或票据内容。
- 提供错误框、上述诊断文件以及 `winver` 的版本／构建号即可。不要上传整个账本、真实附件或完整备份。

新版会检查锁所属机器、进程是否仍存在及创建身份。已确认退出的本机锁可保留原锁信息后恢复；仍有活动实例、身份未知或外机锁时拒绝接管。进程监管只清理本次启动的后代，不按名称结束其他软件。

## 验证范围

构建会在 GitHub Windows Server runner 检查完整解压清单、SHA-256、随包 SQLite、进程树清理、真实 GUI 启动／正常关闭／重开以及旧数据标识保留。Mac 开发验收与 Windows Server CI **不等于 Windows 10 真机验收**。

仍需在目标电脑确认：干净 Windows 10 首次完全断网运行、实际 Alt+F4／任务管理器强制结束／系统关机、机器策略、杀毒软件、中文输入及DPI、真实旧目录升级。程序未签名，未创建安装器或卸载器。异常退出尽量由事务、锁恢复及进程作业对象处理；强制结束、断电或存储硬件丢写不能承诺零损失，请保留独立完整备份。

建议先用 `samples/synthetic-payment.png`（合成示例截图，可作为附件上传）和虚构预支1000.00元／费用1280.50元验收：余额−280.50元；部分报销500.00元后余额保持−280.50元；开票勾选、备份、恢复及正常重开后金额和附件一致。逐项记录本机结果。
