# 钱来 Windows 离线版使用与升级说明

目标环境为 Windows 10 x64。便携包随附 Electron 和 SQLite，目标电脑无需另外安装任何软件。包内 build-info.json 记录来源提交，随 ZIP 提供的同名校验文件记录 SHA-256。

## 首次使用

1. 将完整 ZIP 复制到电脑，用 Windows“全部提取”解压到当前用户可写的本地文件夹（例如“文档”或 D 盘），不要在 ZIP 里直接运行，也不要放进 Program Files 或网络共享。
2. 双击文件夹里的 **Qianlai.exe**。日常使用没有黑色命令窗口。
   - 如果出现蓝色窗口“**Windows 已保护你的电脑**”：先点窗口里的“**更多信息**”，再点下面出现的“**仍要运行**”。这是因为钱来没有购买数字签名证书，Windows 不认识它，并不是检测到病毒。一般只在第一次打开时出现。
   - 如果只看到“不运行”、没有“仍要运行”，说明这台电脑的管理员禁止运行未签名的程序，请找管理员处理，不要自己关闭安全软件。
3. 首次打开是空账本。费用的金额、日期、商户手动填写，可附一张支付截图作为凭证。费用保存后影响余额；公司到账统一登记预支；报销登记只更新进度，不增加到账。允许负余额，“本人垫付”按负余额计算。
4. 用窗口的关闭按钮退出。正在保存时程序会先等保存完成。程序已经打开时再次双击，原来的窗口会回到前面。
5. 左边栏最下面显示“上次备份”的时间；“备份”页最下面显示钱来的版本号。

## 数据在哪里

账本和程序在**同一个文件夹**里。第一次打开后，文件夹里会多出：

| 文件夹 | 里面是什么 |
| --- | --- |
| `数据` | 账本（`qianlai.sqlite`）和全部截图。**最重要** |
| `备份` | 自动备份、手动备份和安全备份 |
| `运行记录` | 程序缓存和启动日志，不含账目 |
| `diagnostics` | 只有运行诊断工具时才有 |

这些文件夹都不要删除，也不要手动修改里面的文件。

## 换电脑或搬到别的位置

1. 关闭钱来。
2. 把**整个钱来文件夹**复制到新电脑（或新位置），例如用 U 盘。
3. 在新位置双击 `Qianlai.exe`，核对余额、费用、预支、报销和截图。

旧位置的文件夹可以先留着，确认新位置没问题后再自行处理。

## 升级到新版本

1. 关闭旧版钱来。
2. 把新版完整解压到**另一个新文件夹**（不要解压到旧文件夹里）。
3. 双击新版的 `Qianlai.exe`，打开“备份”页，点“从其他文件夹恢复或导入…”，选择**旧的钱来文件夹**。
4. 软件会显示旧账本里有多少笔费用、预支、报销和截图。核对无误后输入“恢复备份”，点“备份当前账本并恢复”。
5. 核对余额、费用、报销和截图。旧文件夹不会被修改，确认新版没问题后可以自行删除旧文件夹。

如果新版提示“这个账本是用更新版本的钱来保存的”，说明你选的是更新的版本，请用那个版本打开。早期测试版（文件夹里有 `trial-data` 的版本）的数据新版不能读取。

## 备份与恢复

- **自动备份**：每天打开钱来或第一次记账时自动备份一次，保留最近 30 份。
- **立即备份**：“备份”页点“立即备份”，例如做大量修改之前。手动备份不会被自动删除。
- **备份到 U 盘**：自动备份和账本在同一块硬盘上，硬盘坏了会一起丢失。建议每周插上 U 盘，在“备份”页点“备份到 U 盘…”，选 U 盘。U 盘里会多一个 `钱来备份` 文件夹，每次备份是里面的一个新文件夹，截图在 `钱来备份/截图库`。复制或保管时请把整个 `钱来备份` 文件夹放在一起。
- **恢复、清空之前**，软件都会先自动备份当前账本，需要时可以从备份列表里恢复回来。
- **恢复**：在“备份”页的备份列表里找到要用的那一份，点“用这份恢复”，核对预览，输入“恢复备份”确认。也可以点“从其他文件夹恢复或导入…”，选择 U 盘上 `钱来备份` 里的某一份备份（例如电脑坏了，在新电脑上用新解压的钱来恢复）。
- “备份”页的“打开备份文件夹”和“打开钱来文件夹”可以直接在资源管理器里看到这些文件夹。
- CSV 只是当前筛选的明细表，不含截图，不能用来恢复。

“清空所有数据”需要准确输入“清空当前账本”。清空前会自动备份，清空后费用、预支、报销、开票标记和截图都会删除。不要用清空、改金额或删除记录代替真实退款或退还预支，这些业务还不支持。

## 打不开时

- 如果提示“这个账本正被另一个钱来窗口使用”，先关闭其他钱来窗口再打开。程序崩溃或电脑断电后，这个限制会自动解除，不需要删除任何文件。
- 如果提示账本文件损坏，可以选择“改名保存并重新打开”：软件会把 `数据` 文件夹改名为 `数据-有问题-<时间>` 保存起来（不删除），然后用空账本打开。之后到“备份”页选一份备份恢复。
- 需要求助时，先记录错误框原文和出现步骤，不要删除或修改任何文件，也不要关闭安全软件。
  - 双击 `START-TEST.cmd` 进行一次诊断启动，日志写入 `diagnostics/start-*`。
  - `CHECK-RUNTIME.cmd` 只用临时数据检查 SQLite 能否运行，结果写入 `diagnostics/probe-*`，不打开账本。
  - 启动日志在 `运行记录/logs/startup.log`，只记录启动阶段和退出状态，不记录账目内容。
  - 提供错误框、上述日志、钱来的版本号（“备份”页最下面）和 `winver` 显示的 Windows 版本号即可。不要上传账本、真实截图或备份。

## 验证范围

构建会在 GitHub 的 Windows Server 上检查完整解压清单、SHA-256、随包 SQLite、进程清理，真实启动界面、正常关闭、重新打开，以及把整个文件夹复制到别处后还能打开。这**不等于 Windows 10 真机验收**。

仍需在目标电脑确认：干净的 Windows 10 首次完全断网运行、Alt+F4／任务管理器强制结束／系统关机、杀毒软件、中文输入和显示缩放、从旧文件夹导入。程序没有签名，也没有安装器或卸载器。强制结束、断电或硬盘故障不能承诺零损失，请定期用“备份”页的“备份到 U 盘…”另存一份。

建议先用 `samples/synthetic-payment.png`（合成示例截图，可作为附件上传）和虚构的预支 1000.00 元、费用 1280.50 元试用：余额 −280.50 元；部分报销 500.00 元后余额仍是 −280.50 元；勾选开票、备份、恢复、关闭后重新打开，金额和截图都应一致。逐项记录结果。
